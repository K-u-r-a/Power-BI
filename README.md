I worked on raw data on Data Professional survey.
I transformed the raw data in power query and loaded it into Power BI for visualization.

OBJECTIVE
Do a breakdown of different people's roles and how much they earn.

First of all I did some Data Cleaning in Power Query. I did the folllowing:
-I removed the empty columns
-Split column by delimiter (
-Removed the other column resulting from split
-splitted another column by delimiter, colon
-Removed the column resulting from the split
-Duplicated a column
-Split a column by Digit to Non Digit
-Replaced values in the newly formed column to remove some elements (k,-,+)
-Changed the data type to whole number
-Created a custom average column

I then loaded the clean data to Power BI where I asked the following questions.
Questions 
1.Which titles had the highest salary?
2.Which is he most popular programming language?
3.What is the average salary per country?
4. How happy are they with their current positions?
5. How happy are they with their salaries for their current roles?

Created a dashboard in the report view.

Insights
1.Advanced analytical roles like Data Scientist and Data Engineer command the highest compensation in the data profession.
2.The survey results are heavily influenced by professionals from the U.S
3.Python continues to be the industry standard programming language for data professionals.
4.Entering the data field is generally perceived as challenging but achievable, requiring skills and preparation.
5. Data professionals report moderately good work-life balance,suggesting the field offers reasonable flexibility.
6.Although salaries in data roles are relatively high, many professionals feel only moderately satisfied with their pay.
7. The data profession appears to have a relatively young workforce,  many professionals early careers.
